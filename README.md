# EKOOOL server

Серверная версия EKOOOL для Render.

## Запуск
- Build: `npm install`
- Start: `node server.js`

## Переменные окружения
- `PORT` — Render задаёт автоматически.
- `ADMIN_USERNAME` — необязательно; указанный username получит права администратора при регистрации.

## Админ-панель
Первый зарегистрированный аккаунт получает `admin=true` и `owner=true`, если `ADMIN_USERNAME` не задан.
Админские операции дополнительно проверяются на сервере: права нельзя выдать себе обычным клиентским запросом.

## Важно про данные
База сейчас хранится в `data/db.json`. На Render без постоянного диска данные могут сброситься при пересоздании/миграции сервиса. Для постоянного хранения позже подключим persistent disk или Postgres.
