# EKOOOL — серверная версия

В комплекте:
- `index.html` / `EKOOOL.html` — текущий интерфейс EKOOOL;
- `server.js` — API и сервер;
- `data/db.json` — общая база для MVP;
- `render.yaml` — запуск на Render.

## Локально
Node.js 20+:

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Администратор
**Первый зарегистрированный пользователь автоматически получает права владельца/администратора.** Также можно задать `ADMIN_USERNAME` в переменных окружения — этот username получит права администратора при регистрации.

## Важно
`data/db.json` — простая серверная база для MVP. На хостинге с эфемерным диском данные могут исчезнуть после пересоздания сервиса. Для постоянной эксплуатации лучше подключить PostgreSQL.
